# linav
LiNav Wizard, derived from a portmanteau of License Navigator, is a student project for Syracuse University's IST600 class. 

Building off of existing software like the [OSPO Data Storage Finder](https://opensource.syracuse.edu/data-storage-finder/), LiNav Wizard is a multi-step tool that pinpoints the best possible open source or creative commons license for any given project. LiNav Wizard is intended for those who find licensing complex.

LiNav Wizard was built from the OSPO Data Storage Finder with permission from the original developers. Source code for the OSPO Data Finder can be found [here.](https://github.com/SU-OSPO/data-storage-finder) Anthropic AI tools were used in the coding portion of this project. All AI-generated information has been reviewed extensively, and all AI-generated text has been replaced with that of a human.
