# linav
LiNav Wizard, derived from a portmanteau of License Navigator, is a student project for Syracuse University's IST600 class. 

Building off of existing software like the [OSPO Data Storage Finder](https://opensource.syracuse.edu/data-storage-finder/), LiNav Wizard is a multi-step tool that pinpoints the best possible open source license for any given project. LiNav Wizard is intended for those who are new to software development and those who find licensing complex.
