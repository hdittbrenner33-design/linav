# linav
LiNav Wizard, derived from a portmanteau of License Navigator, is a student project for Syracuse University's IST600 class. B
Building off of existing software like https://choosealicense.com/, LivNav Wizard is a multi-step form that pinpoints the best possible open source license for any given project. LivNav Wizard is intended for those who are new to software development and those who find licensing complex.
